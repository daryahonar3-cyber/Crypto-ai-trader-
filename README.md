# Crypto AI Trader

Kurdish RTL crypto market dashboard packaged as an Android WebView app.

## Build APK
1. Push to GitHub or run the **Build Android APK** workflow from Actions.
2. Open the successful workflow run.
3. Download the **Crypto-AI-Trader-APK** artifact and extract `app-debug.apk`.

The app needs an internet connection for live market data. Signals are informational only, not financial advice; no automatic exchange trading is enabled.
